📋 Todo List App with State Management

A modern Flutter Todo List application built using StatefulWidget and setState() for local state management.

This project demonstrates the fundamentals of Flutter state handling by allowing users to:

➕ Add new tasks
✅ Mark tasks as completed
🗑 Delete tasks
📊 Track completed task count
🌙 Modern dark-themed UI
🚀 Features
Task Management
Add new tasks dynamically
Prevent empty task submissions
Real-time task updates
Completion Tracking
Mark tasks as completed using checkboxes
Visual strike-through effect for completed tasks
Automatic progress count updates
Delete Tasks
Remove unwanted tasks instantly
Updates UI immediately using setState()
Dashboard Header
Displays total completed tasks
Provides quick overview of task progress
Responsive Design
Works across:
Android
iOS
Web
Desktop
